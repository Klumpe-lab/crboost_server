2026-10-10, on the missAlign rollout: I proposed a rigid-only pilot arm, a seed-repeat arm, and a go/no-go
before rolling out. The user was angry ("you are requesting like days of verification work here … let's speed up
the progress") and chose: build the Warp export, then run the paper's schedule on everything.

**Why:** the user is a domain expert who wants progress; multi-day verification gates read as stalling. They also
didn't recognise my shorthand ("rigid run", "pilot") — undefined jargon added to the friction.

**How to apply:** recommend the best-settings path directly; mention a cheap check only if it changes the
action, in one line. Define any coined term on first use. Related [[feedback-dont-gate-stages-on-runtime]],
[[project-agg412-reprocessing-2026-10-04]].
